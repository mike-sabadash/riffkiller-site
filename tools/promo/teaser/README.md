# Табы поверх рилса Mike (Iron Man, 09.11.2026)
- plate.py — плашка с табом в стиле его плашек («7fr», «Main riff / slow»): чёрная, скруглённая, серый заголовок Inter SemiBold, белый таб. Intro: открытая 6-я, бенд за порожком full + ½ (только 0 на 6-й).
- tabscroll.py — бегущий таб над ровным грифом в быстрой части: белое на чёрном, кладётся режимом screen; плейхед внутри линий струн, нота на плейхеде вспыхивает #FFD400. Сетка: начало 11.24 с, доля 0.832 с (по нотам, найденным tools/audio-notes.cjs).
- Сборка: `python3 tabscroll.py | ffmpeg … blend=all_mode=screen …` (команда в истории чата 09.11), под табом мягкое затемнение band.png (без плашки), кадр 1440×2560 50 fps.
