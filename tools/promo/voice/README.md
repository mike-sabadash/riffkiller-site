# Озвучка клонированным голосом Mike (04.11.2026)
- Модель: Qwen/Qwen3-TTS-12Hz-1.7B-Base (Apache 2.0), CPU, bfloat16 (float32 не влезает в 7 ГБ). venv: torch cpu, qwen-tts==0.1.1, faster-whisper, resemblyzer.
- Эталон голоса: запись 01.m4a из папки Drive «video for claud» (8.8 с) + текст "Hi, I'm Mike. I break down famous guitar riffs, one short part at a time." Записи голоса в git не класть.
- vo.py: реплики с таймингом (LINES), по 3 дубля, выбор по совпадению текста (Whisper) + сходству голоса (resemblyzer), ~10 с аудио/мин на 2 CPU. Запускать в фоне (дольше 10 минут).
- mix.py <видео> <выход>: голос (EQ, компрессор) + музыка с сайдчейн-приглушением, loudnorm −14 LUFS, видео копируется.
- Замеры: сходство клон↔живой голос 0.84–0.89 на длинных фразах (живой↔живой 0.88, чужой голос 0.43). С английским эталоном акцент переносится («reef»); с русским эталоном произношение чище, но сходство ниже (0.80).

## v2 (04.11, по замечаниям Mike)
- Звук: первые 5.9 с — только гитара Mike из рилса (reel 0–5.9), затем с 5.9 — кусок рилса с оригиналом (reel 9.96→), склейка на вступлении оригинала, без наложения двух музык. Кадры рилса в середине и в финале сдвинуты на +4.06 с (comp.js reelSrc), чтобы руки совпадали со звуком.
- Музыка между фразами громко (−15 LUFS), под голосом −5 дБ с плавными рампами (mix2.py). Важно: после loudnorm ставить aresample=48000, иначе amix обрезает звук.
- Интонация: 6 связных фраз вместо 11 команд, temperature 1.0, второй эталон = 01 + русская запись 03 (0–13.2 с, «естественная интонация») — даёт более быструю и живую подачу, сходство чуть ниже (0.80–0.82 против 0.84–0.87).
