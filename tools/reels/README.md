# Reels: видео + таб → ролик с бегущим курсором

Отдельная ветка `reels`. Серия Blues licks series (Riff DNA): Mike присылает вертикальное видео
(фраза сыграна один или несколько раз, например быстро, потом медленно) и таб.
Скрипт сам находит каждую ноту таба в звуке и делает ролик 1080×1920 для Instagram Reels.

## Запуск
```
pip install -r tools/reels/requirements.txt      # + ffmpeg в системе
python3 tools/reels/reels.py --video lick.mov --tab lick.tab.txt --out lick.mp4
```
Рядом с роликом появляется `lick.timings.json` — время каждой ноты по проходам.
В консоли строка `check notes [..]` — ноты, в которых скрипт не уверен: посмотреть их в ролике.

Параметры:
- `--title "Blues licks series"`, `--subtitle "Riff DNA"` — надписи сверху;
- `--takes 2` — сколько раз сыграна фраза, если паузы между проходами не нашлись сами;
- `--labels "Take 1 · Fast,Take 2 · Slow"` — подписи проходов на плашке (по умолчанию Fast/Slow по длительности);
- `--panel-top 1384` — высота плашки таба (меньше — выше), чтобы не перекрывать гриф;
- `--timings file.json` — взять время нот из файла (после ручной правки), без анализа звука;
- `--still 2.5` — вместо ролика один кадр PNG на этой секунде (проверка композиции).

## Формат таба
ASCII, строка на струну, сверху тонкая e. Ноты в одной колонке — аккорд.
`3b` — подтяжка, `3b5` — подтяжка до 5, `h`/`p` — легато, `r` — отпускание.
Нота сразу после `b`/`h`/`p` на той же струне считается легато (без удара медиатором).
```
e|--------0-----3b-3--0-------------------------0-----0---|
B|--0--3-----0-----------2--3--2--0-------------------0---|
```
Пример: `examples/blues-lick-01.tab.txt` (+ найденные тайминги).

## Как находятся ноты
1. Звук делится на проходы по паузам.
2. Кандидаты: атаки (onset) и смены высоты (pYIN) — для подтяжек и легато.
3. Каждая нота таба получает оценку в каждом кандидате: сила атаки + совпадение высоты
   (pYIN для одиночных нот, хрома для аккордов).
4. Динамическое программирование выбирает лучшую последовательность по порядку таба,
   штрафуя пропущенные сильные атаки. Самый чистый проход задаёт ритм остальным.

## Композиция (Reels safe zones)
Заголовок — по центру сверху ниже интерфейса Instagram; плашка — стекло со скруглением
по центру с отступами, правый край левее колонки иконок, низ выше подписи.
Курсор как в практике на сайте: мягкая лаймовая полоса с обводкой (`.tab-live-cursor`).
Шрифт — Inter с сайта (`assets/fonts`, SIL OFL).
